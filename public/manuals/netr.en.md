# netr — User Manual

Version matches catalog pricing v3 — chart chat is only on the web.

## Channels

| Action | Where |
|--------|--------|
| Talk with netr | Web `/chat` only |
| Sign up / Sign in | `/register` · `/login` |
| View packages | `/catalog` |
| Top up minutes | `/topup` |
| Contact the team | `/contact` |

LINE is not used to answer charts — opening LINE returns a link back to the web chat.

## Getting started

1. Sign up at `/register` (phone + OTP + birth date, time, and place)
2. Sign in at `/login`
3. Open `/chat` and ask a question

Not signed in: the package button is **Sign in / Sign up**.
Signed in with this package: the button is **Your package** (goes to chat).

## Catalog

| Package | Price | Quota |
|---------|-------|--------|
| Free | ฿0 | 5 minutes / day |
| Prepaid 15 minutes (`prepaid_15m`) | ฿20 | 15 minutes, stackable |
| Plus (`plus_monthly`) | ฿59 / month | 150 minutes / month |

There is no Pro plan (discontinued).

## Minute billing

1. Daily free minutes first (5 minutes)
2. Then Plus quota (if subscribed)
3. Then stacked Prepaid

Minutes follow the real answer time of each question. Minimum 30 seconds. Maximum 5 minutes per question.

## Referrals

Link `/ref/code` — both people get 5 Prepaid minutes when it succeeds.
