# คู่มือผู้ใช้ — QA LAB

จำลองและตรวจสอบเว็บ / API / มือถือที่ **deploy แล้วมี URL** — ไม่ใช่การทดสอบ repo บน Git โดยตรง

## เปิด Portal

เปิด QA LAB จากบัญชี IN Z หรือ URL พอร์ทัลที่ทีมให้

## ตรวจความพร้อมฟรี (ไม่ต้องสมัคร)

1. ใส่ URL ระบบจริง
2. ได้คะแนน 0–100 และข้อค้นพบสูงสุด 5 ข้อ
3. ไม่ใช้ LLM และไม่ต้องสร้างบัญชี

## หลังเข้าสู่ระบบ

1. เปิดจากบัญชี IN Z (SSO)
2. เลือกแพ็กเกจที่ใช้งานอยู่
3. ตั้งเป้าเว็บ/API (และมือถือผ่าน Appium ถ้ามี)
4. รัน Persona → Simulate ในพอร์ทัล
5. อ่านผลและรายงานในแดชบอร์ด

หมายเหตุ: นำคีย์ API มาเอง (BYOK) ตามแพ็กเกจ
