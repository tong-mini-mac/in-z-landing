# คู่มือผู้ใช้งาน SynthComm

สำหรับลูกค้า B2B · SynthComm คือโรงงาน multi-agent สำหรับข้อมูลบทสนทนาสังเคราะห์คุณภาพสูง (ไทย · อังกฤษ · อินโดนีเซีย · เวียดนาม) ช่องทางลูกค้าคือ **Web Portal เท่านั้น** — ไม่มีบอท Telegram หรือ LINE

## SynthComm ทำอะไร

- รับ **หัวข้อ** และ **จำนวนบทสนทนา**
- ค้นคว้าบริบทจากเว็บ (ถ้าเปิดใช้)
- ล็อก locale (เมือง / ธนาคาร / แทร็กกิง) ตามภาษา TH / EN / ID / VI
- ตรวจคุณภาพหลายมิติ
- ส่งมอบไฟล์ JSON / CSV / HTML / PDF ผ่านพอร์ทัล

## เริ่มต้น

1. เข้าสู่ระบบที่ IN Z แล้วเปิด SynthComm จาก **แพ็กเกจของคุณ**
2. ยืนยันอีเมลแล้วได้แพ็กเกจ **ฟรี** (100 บทสนทนา / เดือน)
3. อัปเกรดเป็น Starter / Growth / Business ตามต้องการ หรือซื้อ License / White Label ที่ [inz.lol/pay](https://www.inz.lol/pay)

## License (เครื่องแยกบนคลาวด์ IN Z · ไม่ใช่ไฟล์ให้โหลด)

ขายแบบ **Shopify** — ลูกค้าใช้โดเมนตัวเอง แต่โปรแกรมทั้งหมดอยู่บนเซิร์ฟเวอร์ IN Z ไม่ได้ซอร์ส

```
โดเมนลูกค้า (เช่น ai.ลูกค้า.com)
        │
        │  CNAME  →  synthcomm.inz.lol (หรือโฮสต์ tenant ที่เราให้)
        ▼
  คลาวด์ IN Z — dedicated tenant
  เอนจิน · เวิร์กเกอร์ · control plane · โควตา · วันหมดอายุ
        │
        │  BYOK — คีย์ LLM ของลูกค้า (ไม่ใช้คีย์ IN Z)
        ▼
  DeepSeek / Gemini ของลูกค้า
```

| คำถาม | คำตอบ |
|------|------|
| ตัวโปรแกรมอยู่บนคลาวด์เราไหม | **อยู่ทั้งหมด** เอนจิน เวิร์กเกอร์ control plane อยู่ฝั่ง IN Z |
| แยกจากลูกค้าคนอื่นไหม | **แยก** เป็น dedicated tenant ไม่ใช่พูล SaaS ร่วม |
| API ใช้ของใคร | **ครึ่ง** ส่งจ๊อบ / สถานะ / ดาวน์โหลดผล = IN Z · ค่าโทเค็น LLM = **ลูกค้า BYOK** |
| เอาไปรันในเครื่องตัวเองได้ไหม | **ไม่ได้** นั่นคือ Enterprise IP (฿2,800,000) ไม่ใช่ License |

| ได้ | ไม่ได้ |

### โดเมนตัวเอง (CNAME)

ใน Portal แท็บ **โดเมน** — จำนวนตามแพ็กเกจ

| แพ็ก | โดเมน |
|------|------:|
| Startup License | 1 |
| Professional License | 3 |
| Agency White Label | สูงสุด 10 |

ที่ DNS ของคุณ สร้าง **CNAME** จากโฮสต์ (เช่น `ai.บริษัท.com`) ชี้ไปที่เป้าที่ Portal แสดง แล้วกดส่งคำขอ — รับคำขอแล้ว **ระยะเวลาทำการภายใน 12 ชม.** เลขาจะเปิด host ให้ ถ้าโดเมนเต็มตามแพ็กเกจ ระบบตีกลับว่าเกินข้อกำหนดตาม package

SaaS ใช้โดเมน IN Z ไม่มี CNAME ลูกค้า
