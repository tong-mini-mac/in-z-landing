# คู่มือผู้ใช้ — SynthComm

ใช้งานผ่าน **Web Portal** บนเบราว์เซอร์ — ไม่มีบอท Telegram / LINE

แท็บในพอร์ทัล: **แพ็กเกจ** · **API คีย์ LLM** · **โดเมน** · **สร้างงาน** · **สถานะงาน** · **บัญชี**

## 1. เปิดใช้งาน

1. ล็อกอินที่ [inz.lol](https://www.inz.lol)
2. เปิด SynthComm จาก **แพ็กเกจของคุณ** (SSO)
3. ดูโควต้าที่เหลือในแท็บ **แพ็กเกจ**

## 2. สร้างงาน

1. ไปแท็บ **สร้างงาน**
2. กรอก **Topic** (หัวข้อ/บริบท)
3. เลือกภาษา: Thai · English · Vietnamese · Indonesian
4. ใส่จำนวนบทสนทนา (หักจากโควต้าเดือนนี้)
5. เลือกรูปแบบผลลัพธ์: Bundle / JSON / CSV / PDF
6. (ถ้ามี) อัปโหลด CSV สำหรับ batch
7. กด **ส่งงาน** — เก็บ **Job ID** และ download token ไว้

**ภาษาและ locale**

- Thai — ถ้าไม่ระบุภูมิภาค ระบบใช้ภาคกลางเป็นค่าเริ่มต้น
- English — ถ้าไม่ระบุประเทศ ระบบใช้สิงคโปร์เป็นค่าเริ่มต้น

## 3. ติดตามและดาวน์โหลด

1. ไปแท็บ **สถานะงาน**
2. ใส่ Job ID (และ token ถ้ามี)
3. กด **เช็คสถานะ** หรือ **Auto-poll** จนเป็น `completed`
4. กด **Download**

งานใหญ่ (> 1,000 แถว) ระบบแบ่งสายงานขนานอัตโนมัติ — ติดตามที่ Job ID เดิม

## 4. License — คีย์ LLM (BYOK)

ถ้าใช้ License / White Label ไปแท็บ **API คีย์ LLM** วางคีย์ตามช่อง Research / Writer / QC  
ค่าโทเค็นคิดที่บัญชีคีย์ของคุณ

## 5. License — โดเมนตัวเอง

1. แท็บ **โดเมน** — ดูเป้า CNAME ที่ระบบแสดง
2. สร้างเรคคอร์ด CNAME ที่ DNS ของคุณ
3. ส่งคำขอในพอร์ทัล — ทีมเปิด HTTPS ให้หลังชี้แล้ว

## 6. บัญชี (PDPA)

แท็บ **บัญชี** — ส่งออกข้อมูล JSON หรือลบบัญชีได้ตามสิทธิ PDPA

หมายเหตุ: สิ่งที่โหลดได้คือ**ผลจ๊อบ** — ไม่ใช่ตัวเอนจิน
