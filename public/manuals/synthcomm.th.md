# คู่มือผู้ใช้ — SynthComm

Web Portal เท่านั้น — ไม่มีบอท Telegram หรือ LINE

## เปิดใช้งาน

1. ล็อกอินที่ [inz.lol](https://www.inz.lol)
2. เปิด SynthComm จาก **แพ็กเกจของคุณ** (SSO)
3. เข้าพอร์ทัลแล้วเริ่มสร้างจ๊อบ

## สร้างจ๊อบ

1. ใส่หัวข้อและจำนวนบทสนทนา
2. เลือกภาษา TH / EN / ID / VI
3. เริ่มผลิต — ระบบค้นบริบท (ถ้าเปิด) ล็อก locale แล้วตรวจคุณภาพ
4. ดาวน์โหลดผลเป็น JSON / CSV / HTML / PDF จากพอร์ทัล

## License — ตั้งค่าคีย์ LLM (ถ้าใช้)

ในพอร์ทัลแท็บ **API คีย์ LLM** วางคีย์ตามช่อง:

| ช่อง | ใช้ตอน |
|------|--------|
| วิจัย (Research) | ค้นบริบทจากเว็บก่อนเขียน |
| เขียน (Writer) | สร้างบทสนทนา |
| QC | ตรวจและแก้แถว |

ค่าโทเค็นคิดที่บัญชีคีย์ของคุณ (BYOK)

## License — โดเมนตัวเอง (ถ้าใช้)

1. ในพอร์ทัลแท็บ **โดเมน** สร้างคำขอ
2. ที่ DNS สร้าง **CNAME** ตามเป้าที่พอร์ทัลแสดง
3. กดส่งคำขอ — ทีมเปิด host ให้หลังรับคำขอ

หมายเหตุ: สิ่งที่โหลดได้คือ**ผลจ๊อบ** — ไม่ใช่ตัวเอนจิน
