# คู่มือผู้ใช้ — SynthComm

ใช้งานผ่าน **Web Portal** บนเบราว์เซอร์ — ไม่มีบอท Telegram / LINE

สร้างได้สองแบบ: **บทสนทนา (dialogue)** และ **เอกสาร JSON (document)**

แท็บในพอร์ทัล: **แพ็กเกจ** · **API คีย์ LLM** · **โดเมน** · **สร้างงาน** · **สถานะงาน** · **บัญชี**

## 1. เปิดใช้งาน

1. ล็อกอินที่ [inz.lol](https://www.inz.lol)
2. เปิด SynthComm จาก **แพ็กเกจของคุณ** (SSO) — ไม่ต้อง sign in ในแอปซ้ำ
3. ดูโควต้าที่เหลือในแท็บ **แพ็กเกจ**

## 2. สร้างงาน

1. ไปแท็บ **สร้างงาน**
2. เลือกประเภท: **บทสนทนา** หรือ **เอกสาร**
3. ถ้าเป็นเอกสาร — เลือกรูปแบบ (หรือให้ระบบเดาจากหัวข้อ):
   - แบบฟอร์มร้องเรียน
   - อีเมลลูกค้า ↔ ซัพพอร์ต
   - ประกาศนิติ / หมู่บ้าน
   - ใบแจ้งหนี้ / ใบเสร็จ
   - ตั๋วซัพพอร์ต
4. กรอก **Topic** (หัวข้อ/บริบท)
5. เลือกภาษา: Thai · English · Vietnamese · Indonesian
6. ใส่จำนวนแถว (หักจากโควต้าเดือนนี้ — บทสนทนาและเอกสารใช้โควตาเดียวกัน)
7. เลือกรูปแบบผลลัพธ์: Bundle / JSON / CSV / PDF
8. (ถ้ามี) อัปโหลด CSV สำหรับ batch
9. กด **ส่งงาน** — เก็บ **Job ID** และ download token ไว้

**ภาษาและ locale**

- Thai — ถ้าไม่ระบุภูมิภาค ระบบใช้ภาคกลางเป็นค่าเริ่มต้น
- English — ถ้าไม่ระบุประเทศ ระบบใช้สิงคโปร์เป็นค่าเริ่มต้น

## 3. ติดตามและดาวน์โหลด

1. ไปแท็บ **สถานะงาน**
2. ใส่ Job ID (และ token ถ้ามี)
3. กด **เช็คสถานะ** หรือ **Auto-poll** จนเป็น `completed`
4. กด **Download**

งานใหญ่ (> 1,000 แถว) ระบบแบ่งสายงานขนานอัตโนมัติ — ติดตามที่ Job ID เดิม

## 4. ไฟล์ที่ได้จากจ๊อบ

| รูปแบบที่เลือก | ได้ประมาณนี้ |
|----------------|--------------|
| **Bundle** | ข้อมูล (บทสนทนาหรือเอกสาร) + รายงานสรุป HTML/PDF + QC |
| **JSON** | ข้อมูลและแพ็ก JSON (รวม QC) |
| **CSV** | ตารางแถวข้อมูล |
| **PDF** | รายงานสรุป PDF |

**รายงานสรุปจ๊อบ** (`05_Final_Package.html` / `.pdf`) คือเอกสารรายละเอียดงาน — สรุป topic, QC และตัวอย่าง — แยกจากไฟล์ข้อมูลดิบ

หมายเหตุ: สิ่งที่โหลดได้คือ**ผลจ๊อบ** — ไม่ใช่ตัวเอนจิน
