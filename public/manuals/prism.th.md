# คู่มือผู้ใช้ — PRISM

แอดมินเว็บสำหรับดูแลลีดอสังหา — จับคู่เจตนาและโครงการด้วย SRAG

## เปิดใช้งาน

1. ล็อกอินที่ [inz.lol](https://www.inz.lol)
2. เปิด PRISM จาก **แพ็กเกจของคุณ** หรือลิงก์แอดมินที่ทีมให้
3. เข้าแอดมินเว็บอ้างอิง

## ลำดับงานประจำวัน

1. **ลงทะเบียนลูกค้า / ลีด**
2. **ดูการจำแนกเจตนา** — ระบบแบ่ง High / Medium / Low
3. **จับคู่โครงการ**
   - High: จับคู่โครงการที่มี → คำเชิญ → นัดชม → ติดตาม
   - Medium: โครงการที่จะเปิด → นำเสนอ + วันเปิดตัว → นัด
   - Low: ไม่จับคู่ได้ → ดูรายงานช่องว่างตลาด
4. **ติดตามและนัดหมาย** ตามคิวในแอดมิน
5. **เช็กอินรายเดือน** ตามรอบที่ทีมกำหนด

## สิทธิ์การค้น

แต่ละผู้ใช้ค้นได้เฉพาะชุดข้อมูลที่ได้รับสิทธิ์ (โซน ราคา ประเภท ฯลฯ) — ถ้าค้นไม่เจอ ให้ตรวจสิทธิ์ก่อน
