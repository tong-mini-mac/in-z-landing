# คู่มือผู้ใช้ — Content Creator

SaaS สำหรับภาษาถิ่นไทย (เหนือ · อีสาน · ใต้) และ SEA (เวียดนาม · อินโดนีเซีย · ไทยกลาง · อังกฤษ)

## สิ่งที่แพลตฟอร์มทำ

- พอดแคสต์: อัปโหลด → ถอดเสียง → show notes → clips → RSS
- AI Video: chat แต่งเรื่อง/สคริปต์ → อัปโหลดสื่อ → จับคู่ฉาก → TTS → เรนเดอร์ MP4 → คิว publish

## เริ่มต้น

1. ทดลองฟรี 14 วัน หรือสมัคร
2. Login → Dashboard
3. ไป Billing เพื่ออัปเกรด Starter / Creator / Pro

โควตารายเดือนรีเซ็ตวันที่ 1 ตามเวลาไทย วิดีโอช่วงทดลองติดลายน้ำเสมอ AI clips / ตารางโพสต์ / Guest CRM เริ่มที่ Creator Sponsor CRM / API / white-label เริ่มที่ Pro
