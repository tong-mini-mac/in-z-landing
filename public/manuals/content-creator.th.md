# คู่มือผู้ใช้ — Content Creator

สร้างพอดแคสต์และ AI Video สำหรับภาษาถิ่นไทยและ SEA

## เปิดใช้งาน

1. ล็อกอินที่ [inz.lol](https://www.inz.lol)
2. เปิด Content Creator จาก **แพ็กเกจของคุณ**
3. เข้า Dashboard

## พอดแคสต์

อัปโหลด → ถอดเสียง → show notes → clips → RSS

## AI Video

chat แต่งเรื่อง/สคริปต์ → อัปโหลดสื่อ → จับคู่ฉาก → TTS → เรนเดอร์ MP4 → คิว publish

## โควตาและการอัปเกรด

1. ดู episodes / render / storage ที่เหลือใน Dashboard
2. โควตารายเดือนรีเซ็ตวันที่ 1 ตามเวลาไทย
3. อัปเกรดที่ Billing หรือ [inz.lol/pay](https://www.inz.lol/pay)

## สิ่งที่เปิดใช้ตามแพ็ก

- ทดลอง: วิดีโอติดลายน้ำเสมอ
- Creator ขึ้นไป: AI clips / ตารางโพสต์ / Guest CRM
- Pro: Sponsor CRM / API / white-label
